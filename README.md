## Publish with GitHub Pages

1. On GitHub, create a **public** repository named `engineering-portfolio` under `ChiomaScripts`. Do not initialize it with a README, license, or `.gitignore` if uploading the supplied files with Git.
2. Add `index.html`, `README.md`, and `.nojekyll` to the **root** of the repository on the `main` branch. You can upload them in GitHub's browser interface (hidden `.nojekyll` is optional).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
5. Once GitHub Pages reports a successful deployment, visit **https://chiomascripts.github.io/engineering-portfolio/**.

Publication may take a few minutes. The URL is not live until the repository exists and Pages has deployed successfully.

## Edit

The site is self-contained in `index.html`: update the text, links, and CSS in that file, commit changes to `main`, and GitHub Pages will redeploy.
